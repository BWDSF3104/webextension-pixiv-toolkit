# 極端に狭い画面のレイアウトはスコープ外

**Date**: 2026-11-10
**Status**: 確定（ユーザー指示）

## 決定

- 選択画面 dialog（`Dialog.vue` / `PageSelector.vue`）のレイアウトについて、極端に狭い画面幅での折返し・clip は今後気にしない。
- 現在は修整不要。`max-width`、メディアクエリ、行内折返しの追加制御は導入しない。
- 合格条件は「実際に表示している window size で button が dialog 内におさまりラベルが切れないこと」。固定改行の行グループ（DL to folder が2行目の先頭）が保たれることのみを見る。
- 将来の画面確認で極端な狭幅（button 1個より狭い幅など）で clip が起きる場合は、不合格として扱わない（スコープ外）。確認で狭幅を実測するのは、行グループの固定境界を確認する目的のときに限る。

## 適用範囲

- 上記の dialog footer（選択画面）のみ。content script の panel、options page、popup のレスポンシブ対応にはこの決定を広げない。
